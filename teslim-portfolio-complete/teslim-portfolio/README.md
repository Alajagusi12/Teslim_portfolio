# Abdulwahab Teslim Portfolio

1. Copy your resume into the public folder as Abdulwahab_Teslim_Resume_Final.pdf
2. Double-click start.bat (or run: npm install, then npm run dev)
3. Open http://localhost:3000
4. Before deploying, run: npm run build
5. Review src/data/projects.ts: case study text is a draft; the Nexus source link points to your GitHub profile until you add the repo URL.
6. Deploy: push to GitHub, then import the repo on vercel.com.
